Torium is a sovereign EVM-compatible L1. The public **Torium Testnet** (`torium-testnet-1`,
EVM chain ID `1414484564`) runs valueless tTOR test currency, works with standard EVM tooling
out of the box, and may be reset — treat every deployment and balance as disposable.
