## Loopback endpoints

| Interface     | Endpoint                 |
| ------------- | ------------------------ |
| EVM JSON-RPC  | `http://127.0.0.1:8545`  |
| EVM WebSocket | `ws://127.0.0.1:8546`    |
| Cosmos REST   | `http://127.0.0.1:1317`  |
| Cosmos gRPC   | `127.0.0.1:9090`         |
| CometBFT RPC  | `http://127.0.0.1:26657` |
| local faucet  | `http://127.0.0.1:8080`  |

Validators 1–3 expose diagnostic CometBFT RPC on ports `26757`, `26857` and `26957`; their P2P
ports are `26756`, `26856` and `26956`. Validator 0 uses P2P port `26656` and owns the public client
surface. All host listeners are loopback-only.

The EVM endpoint enables the `eth`, `net` and `web3` namespaces. `debug`, `txpool`, `miner` and
`personal` are unavailable in the active profile. HTTP batches are limited to 100 requests;
`eth_feeHistory` to 100 blocks; log queries to 10,000 blocks and 10,000 results. WebSocket supports
`newHeads` and `logs` only, does not replay missed messages and rejects browser-origin use in the
local profile.

## Canonical configuration

- network IDs and currency metadata: `chain/config/identifiers.json`;
- protocol composition and limits: `chain/config/protocol-v1.json`;
- endpoint exposure and RPC limits: `chain/config/rpc-profile-v1.json`;
- validator trust and finality: `chain/config/trust-model-v1.json`;
- deterministic genesis: `chain/genesis/localnet/genesis.json` and `manifest.json`;
- generated runtime homes: ignored `chain/localnet/.state/<backend>/validator-N`.

Never copy values from `chain/poc/upstream-baseline`; those are historical upstream fixtures, not
Torium identifiers. Public RPC URLs, TLS, rate limits, explorer URLs and production bindings are
undefined and must not be inferred from loopback defaults.
