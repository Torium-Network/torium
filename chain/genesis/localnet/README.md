# Torium valueless localnet genesis

Status: generated local-development artifact only. This is not a public
testnet or mainnet genesis, and tTOR has no value.

`genesis.json`, `manifest.json`, and `SHA256SUMS` are generated by the pinned Go
toolchain from `chain/app/localnet/fixture.json` and the actual `toriumd` module
defaults. Do not edit those three files directly.

```bash
cd chain/app
make genesis
make genesis-check
./build/toriumd genesis validate-genesis ../genesis/localnet/genesis.json
```

The public manifest records every Bech32/EVM address, consensus public key,
allocation, self-delegation, post-genesis balance and expected voting power.
The deterministic fixture scheme is deliberately reproducible and therefore
must never be reused on a public or valuable network. Runtime signing files are
not committed here; localnet orchestration writes them only into ignored local
state.

The genesis supply is exactly `10^27 atorium` (1 billion tTOR). Four validators
start with `25 × 10^18 atorium` self-delegation each, producing 25 voting power
each under `sdk.DefaultPowerReduction = 10^18`. `InitChain` moves exactly
`100 × 10^18 atorium` into the bonded pool without changing total supply.

Staking, distribution, slashing and evidence values are ratified for this
valueless local protocol and emitted in `manifest.json`. They are not public
economics and cannot be copied into a live genesis without the launch-activation
gate and a fresh economic/security review.
