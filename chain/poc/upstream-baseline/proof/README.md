# Baseline proof artifacts

These files are generated by the commands in the parent README against the
exact pins in `pins.json`. They contain only public local-chain addresses,
transaction hashes, capability outcomes, and a wallet UI screenshot. No
mnemonic, private credential, production endpoint, or Torium user data belongs
in this directory.

`fee-history-saturation.json` is produced by the separate 42,000-gas PoC test
profile. That value exists only to fill a block with two plain transfers; it is
not a protocol parameter recommendation.

JSON timestamps and transaction hashes change on every clean run. Review the
support matrix for the stable compatibility contract; use these artifacts to
audit the underlying observations.
